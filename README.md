# Agro Alliance Website

Static company website for Agro Alliance Trading Pte Ltd.

## Structure

- `index.html` - main website page
- `assets/products` - product reference images
- `assets/real-photos` - factory, warehouse and product photos
- `assets/media` - website video assets

## Deployment

This static site can be deployed with Cloudflare Pages, GitHub Pages, Netlify, or any static web host.
